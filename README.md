# AI Medical Triage System

## Overview

The AI Medical Triage System is a simple AI-powered application that analyzes patient symptoms and determines the urgency level of the case. The project is built using Streamlit and integrates the Groq API with Llama3 to generate intelligent responses for basic healthcare triage simulation.

---

## Features

- Symptom-based triage assessment
- AI-generated medical assistance
- Priority classification for patients
- Optimising waiting time at hospitals
- Fast and lightweight application
- Separate dashboard for staff access

---

## Tech Stack

- Python
- Streamlit
- Groq API
- Llm based response generation
- Git & GitHub

---

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/ai-triage-system.git
   cd ai-triage-system
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Add your Groq API key:
   ```python
   GROQ_API_KEY="your_api_key"
   ```

4. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```

---

## Usage

- Enter patient symptoms in the input field
- The AI analyzes the symptoms
- The system returns a triage priority level and response
